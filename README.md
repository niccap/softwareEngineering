# Ingegneria del Software

Codice sorgente ed esempi per il corso di **Ingegneria del Software** della Laurea in Ingegneria Informatica presso l’**Università degli Studi di Salerno — DIEM**.

**Docenti:** Nicola Capuano e Pierluigi Ritrovato.

## Argomenti

- Requisiti, specifiche e Design by Contract.
- Progettazione del software e modellazione UML.
- Documentazione automatica con Doxygen.
- Testing e debugging, con CUnit e JUnit.
- Automazione del build con Make e Maven.
- Controllo delle revisioni con Git.

Gli esempi in **C e Java** accompagnano le lezioni e le attività di laboratorio.

## Utilizzo

```bash
git clone https://github.com/niccap/softwareEngineering.git
```

Consultare gli esempi seguendo le indicazioni fornite durante il corso. Materiali didattici e istruzioni per il progetto sono disponibili sulla [piattaforma e-learning di Ateneo](https://elearning.unisa.it).
